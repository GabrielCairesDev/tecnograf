# TECNOGRAF · Gráfica Rápida

Página de links da TECNOGRAF (substitui o Linktree), feita em HTML, CSS e JavaScript puros — sem dependências, sem build.

🎨 Comunicação visual · 👕 Sublimação · 🏆 Produtos personalizados
📍 R. Padre Leal, 601 - Centro, Buriti dos Lopes - PI

## Estrutura

```
index.html   → conteúdo e links
style.css    → visual (cores no topo, em :root)
script.js    → botão de compartilhar e animações
assets/      → logo
```

## Editar links

Todos os links estão no `index.html`, dentro de `<nav class="links">`. Para adicionar um botão, copie um bloco `<a class="btn">…</a>` e troque o texto e o `href`.
